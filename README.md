# Maria Ansari — Software Engineer Portfolio

A modern, responsive personal portfolio website showcasing my software engineering skills, projects, experience, education, and technical journey.

## 🌐 About

Hi, I'm Maria Ansari, a Software Engineer from Mumbai, India.

I'm passionate about building practical, scalable, and user-focused applications. My interests span backend development, full-stack development, cloud technologies, REST APIs, and Java-based software development.

This portfolio highlights my technical skills, professional experience, projects, education, and ways to connect with me.

---

## ✨ Features

- Modern responsive portfolio design
- Light and dark mode
- Personal profile section
- About me section
- Technical skills showcase
- Project showcase with technology details
- Professional experience section
- Education section
- Downloadable CV
- LinkedIn and GitHub integration
- Direct email contact
- Functional contact form
- Gmail-powered contact notifications
- Responsive design for desktop, tablet, and mobile
- Smooth animations and modern UI
